# Price Sync (پروژه اندروید)

این پروژه یک **Accessibility Service** است که وقتی دو اپ به‌صورت
Split-screen باز باشند (مثل عکسی که فرستادید)، اعداد جدول اپ اول
(منبع) را می‌خواند و با کلیک شبیه‌سازی‌شده روی دکمه‌های + / - در اپ
دوم (مقصد)، عدد آن را طبق فرمول `مقدار منبع + فاصله` تنظیم می‌کند.

همه‌ی تنظیمات (نام پکیج دو اپ، فاصله/آفست هر فیلد، تعداد کلیک مجاز،
تاخیر بین کلیک‌ها) از **داخل خود اپ** قابل تغییر است — نیازی به
کامپایل دوباره نیست.

## نحوه کار الگوریتم
سرویس هر مرحله فقط چک می‌کند مقدار فعلی در اپ مقصد کمتر یا بیشتر از
مقدار هدف است و یک کلیک + یا - می‌زند، بعد دوباره می‌خواند. به همین
دلیل لازم نیست بدانید هر کلیک دقیقاً چند تومان تغییر می‌دهد.

## مراحل راه‌اندازی
1. پروژه را در Android Studio باز کنید (Open an existing project) و صبر
   کنید Gradle sync تمام شود.
2. اپ را روی گوشی خودتان نصب کنید (Run).
3. هر دو اپ (منبع و مقصد) را به‌صورت Split-screen باز کنید، دقیقا مثل
   اسکرین‌شاتی که فرستادید.
4. اپ Price Sync را باز کنید، دکمه‌ی «باز کردن تنظیمات Accessibility»
   را بزنید و سرویس Price Sync را روشن کنید.
5. نام پکیج دو اپ را وارد کنید. برای پیدا کردن نام پکیج هر اپ:
   تنظیمات گوشی → برنامه‌ها → انتخاب اپ → «نام پکیج» یا با اپی مثل
   «Package Name Viewer» از Play Store.
6. دکمه‌ی «ذخیره تنظیمات» و بعد «پیش‌نمایش اعداد شناسایی‌شده» را بزنید.
   یک لیست از اعداد پیدا‌شده در هر دو اپ (با شماره ایندکس) و لیست
   دکمه‌های قابل کلیک اپ مقصد نشان داده می‌شود.
7. با کمک همین پیش‌نمایش، در بخش JSON تنظیمات فیلدها این مقادیر را
   برای هر ردیف اصلاح کنید:
   - `sourceIndex`: ایندکس عدد مرجع در اپ منبع
   - `targetValueIndex`: ایندکس عدد فعلی در اپ مقصد
   - `targetPlusIndex` / `targetMinusIndex`: ایندکس دکمه‌های + و - مربوط
     به همان ردیف در لیست «دکمه‌های قابل کلیک»
   - `offset`: فاصله‌ای که می‌خواهید اضافه/کم شود (مثلاً 50000 یا
     ‎-50000‎)
8. دوباره ذخیره کنید. با دکمه‌ی «همگام‌سازی دستی» یک بار تست کنید که
   دکمه‌های درست کلیک می‌شوند، بعد سوییچ «همگام‌سازی خودکار» را روشن
   کنید تا با هر تغییر در اپ منبع، اپ مقصد خودکار به‌روزرسانی شود.

## رفع خطای «Could not find com.android.tools.build:gradle:...»
این خطا یعنی Android Studio به `dl.google.com` (سرور Maven گوگل) وصل
نمی‌شه — یه مشکل شبکه‌ست، نه مشکل پروژه. دو راه:
1. یک VPN روشن کنید و دوباره Sync بزنید (File → Sync Project with
   Gradle Files).
2. یا بدون VPN: فایل `build.gradle` (روت پروژه) از قبل با mirror های
   Aliyun و myket.ir آپدیت شده تا اگه `dl.google.com` در دسترس نبود،
   از این آدرس‌ها دانلود کنه. اگه باز هم Sync طولانی/گیر کرد (چون اول
   سعی می‌کنه google() رو امتحان کنه و timeout می‌خوره)، می‌تونید موقتاً
   خط‌های `google()` و `mavenCentral()` را در همین فایل کامنت کنید تا
   فقط از mirror ها استفاده بشه.
3. اگه بعد از این، خطای مشابهی درباره‌ی دانلود خود Gradle (نه پلاگین)
   از `services.gradle.org` دیدید، بگید تا فایل `gradle-wrapper.properties`
   رو هم به یک mirror اضافه کنم.

## ساخت APK بدون Android Studio (با GitHub Actions)
اگه دردسر نصب SDK محلی زیاد شد، این راه همه‌ی اون مشکلات رو دور
می‌زنه، چون SDK روی سرور گیت‌هاب دانلود می‌شه نه روی سیستم شما:

1. یک حساب رایگان در github.com بسازید (اگه ندارید).
2. یک ریپازیتوری جدید بسازید (دکمه‌ی سبز «New»)؛ می‌تونه Private باشه.
3. توی صفحه‌ی ریپازیتوری خالی، روی «uploading an existing file» کلیک
   کنید و **تمام محتوای همین پوشه‌ی PriceSyncApp** (شامل پوشه‌ی مخفی
   `.github`) رو بکشید و رها کنید. اگه سایت پوشه‌ی `.github` رو از
   درگ‌ودراپ قبول نکرد، باید `git` روی سیستم‌تون نصب کنید و با دستورات
   `git init` / `git add .` / `git commit` / `git push` آپلود کنید؛
   بگید تا دستورات دقیقش رو هم بدم.
4. بعد از آپلود و Commit، به تب **Actions** بالای صفحه‌ی ریپازیتوری
   برید. یک workflow به اسم «Build APK» باید خودش شروع بشه (چند
   دقیقه طول می‌کشه).
5. وقتی تیک سبز خورد، روی همون اجرا کلیک کنید، پایین صفحه بخش
   **Artifacts** یک فایل به اسم `PriceSync-debug-apk` هست — دانلودش
   کنید و از حالت zip خارجش کنید تا فایل `app-debug.apk` رو بگیرید.
6. همون APK رو به گوشی‌تون منتقل کنید و نصب کنید (لازمه اجازه‌ی
   «نصب از منابع ناشناس» رو برای همون اپی که فایل رو باهاش باز
   می‌کنید فعال کنید).

از این به بعد، هر تغییری که در تنظیمات JSON/کد بدید و دوباره روی
گیت‌هاب آپلود (push) کنید، یک APK جدید خودکار ساخته می‌شه — دیگه
اصلاً لازم نیست SDK/Build-Tools رو روی سیستم خودتون نصب کنید.

## نکات مهم و هشدار
- **این ابزار به‌جای شما روی دکمه‌های اپ معاملاتی کلیک می‌زند.** حتماً
  قبل از روشن کردن حالت خودکار، رفتار آن را با مبالغ/فاصله‌های کوچک و
  زیر نظر خودتان تست کنید تا از خطای ایندکس یا قیمت‌گذاری اشتباه
  جلوگیری شود.
- خودکارسازی تعامل با یک پلتفرم معاملاتی ممکن است با قوانین و شرایط
  استفاده (ToS) آن پلتفرم در تضاد باشد و در برخی موارد باعث مسدود شدن
  حساب شود؛ بهتر است قبل از استفاده‌ی جدی، این موضوع را با ارائه‌دهنده
  همان سامانه معاملاتی بررسی کنید.
- سرویس Accessibility دسترسی گسترده‌ای به محتوای صفحه دارد؛ این اپ را
  فقط روی گوشی خودتان و برای همین کار نصب کنید، و اگر روزی خواستید آن
  را در Google Play منتشر کنید، Google معمولاً استفاده از Accessibility
  برای غیر از کمک به کاربران دارای معلولیت را رد می‌کند (برای استفاده‌ی
  شخصی/نصب مستقیم APK مشکلی ندارد).
- اگر ظاهر یکی از دو اپ بعد از آپدیت تغییر کند، ممکن است ایندکس‌ها
  عوض شوند؛ کافی است دوباره از دکمه‌ی «پیش‌نمایش» استفاده کنید و JSON
  را اصلاح کنید.
